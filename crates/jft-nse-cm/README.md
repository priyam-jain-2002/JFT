# jft-nse-cm

Authoritative Rust data plane for NSE Cash Market Order and Trade data.

This crate owns source integrity, layout dispatch, fixed-width framing/parsing, exact jiffy handling, canonical events, lifecycle reduction, order-book replay, reconciliation, quarantine, and deterministic output hashes.

Python must consume the versioned canonical artifacts emitted by this crate. It must not parse raw NSE Order/Trade bytes or maintain a second authoritative order book.

Implemented evidence-backed slices currently cover content-based empty/gzip/ZIP/ASCII/unknown-binary signature detection; strict CM Full/Trim filename decoding; homogeneous stream-set discovery without a fixed stream count; exact data/trigger stream-member pairing; logical-delivery orchestration with nested errors; deterministic multi-delivery inventory discovery with exact filename rejections; exact LF framing with borrowed corrupt-tail evidence; lazy byte-addressable outcomes over caller-provided source bytes; current Trim/Full and historical Full 87/100/101 Order/Trade layout maps; validated date dispatch including the one-day Full exception and Trim introduction; date-dispatched Full structural framing plus per-field observed-byte profiles with exact source-byte/residue reconciliation; strict Trim field parsing; an order-only entry/modify/cancel reducer with isolated `PO`/`RM`/`CA` identities and non-mutating cross-session anomalies; checked price-level projection from active orders with typed empty/one-sided/normal/locked/crossed top-of-book evidence; caller-ordered single-source Trim Order replay with exact active/entry/failure provenance, count reconciliation, and an allocation-free successful-transition observer; exact paired-delivery validation and deterministic independent per-stream Order replay that retains stream context without merging; both-sided single-source Trim trade-reference classification plus all-stream candidate collection that preserves duplicates and side mismatches without temporal claims; and Order/Trade jiffy range/tie/regression profiling across exact paired-delivery members with deterministic stream ordering and pairwise range-overlap evidence. Filesystem enumeration, profiling on representative current data, Full semantic parsing, durable canonical transition output, disk-backed input/decompression, temporal/cross-stream replay ordering and hashes, validated session transitions/daily reset, trade-driven quantity semantics, trigger verification, and canonical columnar output are not implemented yet.
